🧩 App Ka Simple Flow Aur 6 Topics Ka Connection

Sirf 2 simple screens hain — bilkul Lab 1 se Lab 5 ke level ke mutabiq:

🔑 1. SharedPreferences (Creator Name)

App Bar Mein Channel Name: Default name 'Maaz Creator' device disk par save hota hai. Edit button dabane par dialog khulta hai aur naya naam SharedPreferences.setString('creatorName', val) se permanently save ho jata hai.

🗄️ 2. SQFLite (Local Database)

DBHelper Singleton: content_creator.db ke andar contents table bani hui hai (id, title, platform, views). User jab '+' button se video post dalta hai toh woh seedha SQLite mein insert hoti hai.

⚡ 3. Provider State Management

ContentProvider (ChangeNotifier): UI ko database ke sath sync rakhta hai. Video add ya delete hote hi notifyListeners() call hota hai aur bina setState ke UI aur Total Views counter update ho jate hain.

📱 4. ListView.builder (Widgets)

Recycling List: Creator ke tamam uploads (YouTube, TikTok, Instagram) clean Cards aur ListTiles mein display hotay hain with platform icon, views count aur delete button.

🧭 5. Navigation Using Named Routes

MaterialApp.routes: Root path '/' dashboard screen pe khulta hai aur top trending icon dabane par Navigator.pushNamed(context, '/trends') se API screen khulti hai.

🌐 6. REST API Client (FutureBuilder)

Remote Trends Screen: http.get() se live trending ideas fetch hotay hain aur FutureBuilder loading spinner aur data list handle karta hai.

🎯 Viva Voce Expected Questions & To-The-Point Answers (Roman Urdu)

Har sawal par click karein aur seedha woh jawab parhein jo Sir ke samne bolna hai.

📂 Topic 1: SQFLite Database Helper

SQFLite Sir: "Beta, DBHelper ko Singleton pattern kyun banaya hai?" ▼
Roman Urdu Jawab: "Sir, SQLite database connection ek heavy resource hoti hai. Agar har dafa naya object bane ga toh bar bar file open hogi jis se Database Lock aur Memory Leak ho sakta hai. Is liye private constructor DBHelper._init() aur static instance bana kar hum ensure karte hain ke poori app mein sirf ek hi open database connection rahay."
SQFLite Sir: "openDatabase mein onCreate kab chalta hai?" ▼
Roman Urdu Jawab: "Sir, onCreate callback sirf pehli baar chalta hai jab mobile mein database ki file pehli dafa create hoti hai. Iske andar hum CREATE TABLE contents (...) ki SQL query chalate hain taake table ban jaye."

🔑 Topic 2: SharedPreferences

SharedPrefs Sir: "Aapne SharedPreferences mein kya store karwaya hai aur kyun?" ▼
Roman Urdu Jawab: "Sir, SharedPreferences lightweight key-value data ke liye best hota hai. Humne isme Creator ka Channel Name (jaise 'Maaz Creator') store karwaya hai. User jab edit karta hai toh woh disk pe save ho jata hai aur app restart hone ke baad bhi wahi naam AppBar mein load hota hai."
SharedPrefs Sir: "SharedPreferences.getInstance() Future kyun return karta hai?" ▼
Roman Urdu Jawab: "Sir, kyunki SharedPreferences ko physical flash storage (XML file) se data RAM mein asynchronously read karna hota hai. Yeh disk I/O operation hota hai, agar yeh asynchronous na ho toh UI thread block ho jaye gi aur screen freeze ho sakti hai."

⚡ Topic 3: State Management (Provider)

Provider Sir: "notifyListeners() ka asal maqsad kya hai?" ▼
Roman Urdu Jawab: "Sir, ChangeNotifier Observer pattern follow karta hai. Jab bhi hum SQLite mein naya content insert ya delete karte hain, toh hum notifyListeners() call karte hain. Yeh UI ko signal bhejta hai ke data update ho gaya hai, aur sirf relevant widgets re-render hotay hain bina poori screen pe setState lagaye."
Provider Sir: "context.watch aur context.read mein kya farq hai?" ▼
Roman Urdu Jawab: "Sir:
• context.watch<ContentProvider>() changes ko listen karta hai: jab bhi notifyListeners chalta hai yeh widget ko rebuild karta hai (ise hum build() method mein use karte hain).
• context.read<ContentProvider>() sirf ek dafa call karne ke liye hota hai bina subscription ke (ise hum button ke onPressed mein functions call karne ke liye use karte hain)."

🧭 Topic 4: Navigation Using Named Routes

Routes Sir: "Named routes kyun use kiye hain simple Navigator.push ke muqable mein?" ▼
Roman Urdu Jawab: "Sir, Named Routes ka faida yeh hai ke routing centralized ho jati hai MaterialApp.routes map ke andar. Code mein hardcoded MaterialPageRoute bar bar likhne ki bajaye hum seedha Navigator.pushNamed(context, '/trends') likhte hain jo clean aur maintainable hota hai."

📱 Topic 5: ListView.builder Widget

Widgets Sir: "ListView.builder normal ListView(children: []) se behtar kyun hai?" ▼
Roman Urdu Jawab: "Sir, normal ListView(children: []) tamam items ko ek hi waqt mein memory mein load kar deta hai, agar 1000 items hon toh app hang ho sakti hai. Jabke ListView.builder Lazy Loading aur View Recycling use karta hai — yani sirf wohi cards render karta hai jo mobile screen par is waqt nazar aa rahay hotay hain."

🌐 Topic 6: REST API Calling & FutureBuilder

API Sir: "FutureBuilder API calling mein kis tarah kaam kar raha hai?" ▼
Roman Urdu Jawab: "Sir, FutureBuilder http.get() ke response ko monitor karta hai aur 3 conditions handle karta hai:
1. ConnectionState.waiting: Jab tak request chal rahi ho tab tak CircularProgressIndicator dikhata hai.
2. snapshot.hasError: Agar internet na ho ya server error aaye toh error message render karta hai.
3. snapshot.hasData: Response milte hi jsonDecode shuda data ko ListView.builder mein display kar deta hai."

import 'package:flutter/foundation.dart';
import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';
import '../models/content_item.dart';

class DBHelper {
  static final DBHelper instance = DBHelper._init();
  static Database? _database;

  DBHelper._init();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDB('content_creator.db');
    return _database!;
  }

  Future<Database> _initDB(String filePath) async {
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: _createDB,
    );
  }

  Future _createDB(Database db, int version) async {
    await db.execute('''
      CREATE TABLE contents (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        title TEXT NOT NULL,
        platform TEXT NOT NULL,
        views INTEGER NOT NULL
      )
    ''');
  }

  Future<int> insertContent(ContentItem item) async {
    final db = await database;
    return await db.insert('contents', item.toMap());
  }

  Future<List<ContentItem>> getContents() async {
    final db = await database;
    final result = await db.query('contents', orderBy: 'id DESC');
    return result.map((map) => ContentItem.fromMap(map)).toList();
  }

  Future<int> deleteContent(int id) async {
    final db = await database;
    return await db.delete(
      'contents',
      where: 'id = ?',
      whereArgs: [id],
    );
  }
}
📁 open_ended_lab/lib/providers/content_provider.dart (Provider Engine) 
import 'package:flutter/material.dart';
import '../database/db_helper.dart';
import '../models/content_item.dart';

class ContentProvider extends ChangeNotifier {
  final DBHelper _dbHelper = DBHelper.instance;

  List<ContentItem> _contents = [];
  bool _isLoading = false;

  List<ContentItem> get contents => _contents;
  bool get isLoading => _isLoading;
  int get totalVideos => _contents.length;
  int get totalViews => _contents.fold(0, (sum, item) => sum + item.views);

  Future<void> loadContents() async {
    _isLoading = true;
    notifyListeners();

    _contents = await _dbHelper.getContents();
    _isLoading = false;
    notifyListeners();
  }

  Future<void> addContent(ContentItem item) async {
    await _dbHelper.insertContent(item);
    await loadContents();
  }

  Future<void> deleteContent(int id) async {
    await _dbHelper.deleteContent(id);
    await loadContents();
  }
}
