📂 Topic 1: SQFLite Relational Database

SQFLite Why did you implement DatabaseHelper as a Singleton pattern? ▼
Direct Answer: "Sir, SQLite database connections are heavy, costly resources. If every screen opened a new connection, it would lead to memory leaks and database lock exceptions (Database Locked error). By making DatabaseHelper a singleton (private constructor _init() and static final instance), we ensure exactly one shared instance and open connection exists throughout the app lifecycle."
SQFLite What is the difference between rawQuery/execute and helper methods like insert(), update(), delete()? ▼
Direct Answer: "Sir, db.execute() and db.rawQuery() take raw SQL strings, which are prone to syntax errors and SQL Injection attacks if parameters aren't sanitized. Helper methods like db.insert('table', map) and db.update(..., whereArgs: [id]) automatically sanitize inputs, map Dart types to SQL types, and return integer statuses (e.g. inserted row ID or affected row count)."
SQFLite Where is the SQLite file physically saved on the user's Android phone? ▼
Direct Answer: "Sir, on Android it is stored in the app's internal private sandboxed directory: /data/data/<package_name>/databases/fleet_manager.db. We locate this path dynamically using getDatabasesPath() from the sqflite package."

🔑 Topic 2: SharedPreferences

SharedPrefs Why didn't you store your Vehicle fleet list inside SharedPreferences? ▼
Direct Answer: "Sir, SharedPreferences is designed strictly for lightweight primitive key-value data (booleans, strings, ints, doubles). It cannot perform indexed SQL queries, table joins, transactions, or filtering. Storing hundreds of relational records in SharedPreferences is an anti-pattern. That's why we use SQFLite for relational data and SharedPreferences for officer session state (isLoggedIn, badgeId)."
SharedPrefs Why does SharedPreferences.getInstance() return a Future? ▼
Direct Answer: "Sir, because SharedPreferences has to read an XML file from the physical flash disk into device RAM asynchronously. Disk I/O must be asynchronous (Future) so it does not block the main Flutter UI thread (which would cause frame drops or app freezing)."

⚡ Topic 3: State Management with Provider

Provider What is the critical difference between context.watch() and context.read()? ▼
Direct Answer: "Sir:
• context.watch<FleetProvider>() listens to changes: whenever notifyListeners() is called, the widget rebuilds! Used inside the build() method.
• context.read<FleetProvider>() reads the provider once without subscribing to updates. Used inside event handlers and button callbacks (e.g. onPressed) so we don't trigger unnecessary widget rebuilds."
Provider What does notifyListeners() do behind the scenes? ▼
Direct Answer: "Sir, ChangeNotifier implements the Observer Design Pattern. When notifyListeners() is triggered, it iterates over its internal registry of listening widgets (Consumers or context.watch callers) and calls their markNeedsBuild() method, queuing them for a selective frame repaint."

🧭 Topic 4: Navigation Using Named Routes

Routes Why use Named Routes over Navigator.push(MaterialPageRoute(...))? ▼
Direct Answer: "Sir, Named Routes provide centralized route management in MaterialApp.routes. In large apps, having hardcoded MaterialPageRoute scattered across dozens of files creates tight coupling and makes deep-linking or modifying navigation paths extremely difficult. Named routes allow clean routing using strings like '/vehicles'."
Routes What is the difference between pushNamed and pushReplacementNamed? ▼
Direct Answer: "Sir, pushNamed pushes a new screen onto the stack on top of the current screen, so pressing Back returns to the previous screen. pushReplacementNamed destroys and replaces the current route in the stack. We use pushReplacementNamed during Login so the user cannot click the Android hardware back button to return to the Login screen after logging in."

📱 Topic 5: ListView & GridView Widgets

Widgets Why must you use ListView.builder instead of standard ListView(children: [...])? ▼
Direct Answer: "Sir, ListView(children: [...]) instantiates every child widget into memory upfront, causing severe lag and OOM crashes if there are 1,000 items. ListView.builder employs on-demand view recycling (Lazy Loading): it only renders items currently visible on the screen viewport, ensuring a constant 60 FPS performance."
Widgets What is SliverGridDelegateWithFixedCrossAxisCount in GridView? ▼
Direct Answer: "Sir, it is the delegate that controls the layout grid mathematics. crossAxisCount: 2 tells Flutter to layout 2 columns across the horizontal axis, and childAspectRatio: 0.82 defines the width-to-height ratio of each card item so they don't overflow."

🌐 Topic 6: REST API Calling & FutureBuilder

API Explain how FutureBuilder handles the 3 asynchronous lifecycle states. ▼
Direct Answer: "Sir, FutureBuilder inspects AsyncSnapshot:
1. snapshot.connectionState == ConnectionState.waiting: API request is in-flight; we display CircularProgressIndicator().
2. snapshot.hasError: Network request failed (e.g. 404, 500, or no Wi-Fi); we display the error and a Retry button.
3. snapshot.hasData: Successful 200 OK response; we pass snapshot.data directly into ListView.builder."
API Why must jsonDecode(response.body) be used before mapping to Dart models? ▼
Direct Answer: "Sir, response.body is a raw string of bytes received across the network. jsonDecode() parses that string into dynamic Dart Maps or Lists, which we then pass into our strongly-typed factory constructor SafetyBulletin.fromJson(item) to avoid runtime type errors."

import 'package:sqflite/sqflite.dart';
import 'package:path/path.dart';
import '../models/vehicle.dart';

class DatabaseHelper {
  static final DatabaseHelper instance = DatabaseHelper._init();
  static Database? _database;

  DatabaseHelper._init();

  Future<Database> get database async {
    if (_database != null) return _database!;
    _database = await _initDB('fleet_manager.db');
    return _database!;
  }

  Future<Database> _initDB(String filePath) async {
    final dbPath = await getDatabasesPath();
    final path = join(dbPath, filePath);

    return await openDatabase(
      path,
      version: 1,
      onCreate: _createDB,
    );
  }

  Future _createDB(Database db, int version) async {
    await db.execute('''
      CREATE TABLE vehicles (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        plateNumber TEXT NOT NULL,
        modelName TEXT NOT NULL,
        vehicleType TEXT NOT NULL,
        mileage INTEGER NOT NULL,
        fuelLevel INTEGER NOT NULL,
        status TEXT NOT NULL
      )
    ''');
  }

  Future<int> insertVehicle(Vehicle vehicle) async {
    final db = await database;
    return await db.insert('vehicles', vehicle.toMap());
  }

  Future<List<Vehicle>> getAllVehicles() async {
    final db = await database;
    final result = await db.query('vehicles', orderBy: 'id DESC');
    return result.map((map) => Vehicle.fromMap(map)).toList();
  }

  Future<int> updateVehicle(Vehicle vehicle) async {
    final db = await database;
    return await db.update(
      'vehicles',
      vehicle.toMap(),
      where: 'id = ?',
      whereArgs: [vehicle.id],
    );
  }

  Future<int> deleteVehicle(int id) async {
    final db = await database;
    return await db.delete(
      'vehicles',
      where: 'id = ?',
      whereArgs: [id],
    );
  }
}
📁 open_ended_lab/lib/providers/fleet_provider.dart (Provider Engine) 
import 'package:flutter/material.dart';
import '../database/database_helper.dart';
import '../models/vehicle.dart';

class FleetProvider extends ChangeNotifier {
  final DatabaseHelper _dbHelper = DatabaseHelper.instance;

  List<Vehicle> _vehicles = [];
  bool _isLoading = false;
  bool _isGridView = false;
  String _searchQuery = '';
  String _statusFilter = 'All';

  List<Vehicle> get vehicles {
    return _vehicles.where((vehicle) {
      final matchesSearch = vehicle.plateNumber.toLowerCase().contains(_searchQuery.toLowerCase()) ||
          vehicle.modelName.toLowerCase().contains(_searchQuery.toLowerCase()) ||
          vehicle.vehicleType.toLowerCase().contains(_searchQuery.toLowerCase());
      final matchesStatus = _statusFilter == 'All' || vehicle.status == _statusFilter;
      return matchesSearch && matchesStatus;
    }).toList();
  }

  bool get isLoading => _isLoading;
  bool get isGridView => _isGridView;
  String get statusFilter => _statusFilter;

  int get totalCount => _vehicles.length;
  int get activeCount => _vehicles.where((v) => v.status == 'Active').length;
  int get maintenanceCount => _vehicles.where((v) => v.status == 'Maintenance').length;
  int get groundedCount => _vehicles.where((v) => v.status == 'Grounded').length;

  Future<void> loadVehicles() async {
    _isLoading = true;
    notifyListeners();
    _vehicles = await _dbHelper.getAllVehicles();
    _isLoading = false;
    notifyListeners();
  }

  Future<void> addVehicle(Vehicle vehicle) async {
    await _dbHelper.insertVehicle(vehicle);
    await loadVehicles();
  }

  Future<void> updateVehicle(Vehicle vehicle) async {
    await _dbHelper.updateVehicle(vehicle);
    await loadVehicles();
  }

  Future<void> deleteVehicle(int id) async {
    await _dbHelper.deleteVehicle(id);
    await loadVehicles();
  }

  void toggleViewMode() {
    _isGridView = !_isGridView;
    notifyListeners();
  }

  void setStatusFilter(String status) {
    _statusFilter = status;
    notifyListeners();
  }

  void setSearchQuery(String query) {
    _searchQuery = query;
    notifyListeners();
  }
}
